# Andy Menutti Multitrack

An interactive CV laid out like a recording session. Each branch of the career (film, stage, live and festivals, business and advocacy, sound art and hardware, full-stack web, AI and protocols) is a track. A playhead moves from 2000 to 2027 and stops at fourteen chapters. Each chapter explains the context, the problem and how it was solved.

- English and Spanish: use the EN / ES switch, or open `index.html#en` / `index.html#es`.
- Controls: play/pause, previous/next, optional sound. Keyboard: Space, ← →.
- Click a region on the timeline to jump to it. Click a track name to play only that branch.

Single static file, no build step. Open `index.html` in a browser or deploy the folder to any static host (Vercel, GitHub Pages, Netlify).
